# UniVent – University Event Management System 🎓

UniVent is a full-stack university event management platform that allows students to explore clubs, discover upcoming events, and RSVP seamlessly. It also provides admin functionality for managing and creating events.

## 🚀 Features
- Club Management
- Event Creation & Management
- RSVP System
- Admin Login Authentication
- Dynamic Event Filtering
- REST API Integration
- PostgreSQL Database Connectivity

## 🛠️ Tech Stack
- Java Servlets
- JSP
- JDBC
- PostgreSQL
- JavaScript
- HTML/CSS
- Apache Tomcat

## ⚙️ How to Run
1. Clone the repository
2. Import the project into Eclipse
3. Configure PostgreSQL database
4. Run the project on Apache Tomcat
5. Open:

```bash
http://localhost:8080/Univent/index.html
```
